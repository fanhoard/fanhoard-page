**TL;DR** — FanHoard กำลังได้รับการออกแบบใหม่ทั้งเว็บ และอัปเดตนี้คือการวางรากฐาน design token ที่ทุกหน้าทุกส่วนประกอบใช้ร่วมกัน สู่ "Design Language v3": พื้นหลังสีขาวสะอาดตา, มุมโค้งมนมากขึ้น, เส้นขอบเบาหวิวและเงานุ่มขึ้น ทุกหน้าที่เข้าชมตอนนี้สงบและทันสมัยขึ้นแล้ว — แต่ละระบบจะถูกยกใหม่ทีละส่วนในอัปเดตถัดไป

### ใหม่

- **Design Token แบบ White-First (FanHoard Design Language v3)**
  พื้นหลังหน้าเว็บเปลี่ยนเป็นขาวนุ่ม (`#FAFAFC`) แทนเทาอมฟ้าเดิม การ์ดสีขาวบริสุทธิ์ลอยอยู่ด้านบนให้เห็นความลึกชัด ข้อความยังคง contrast สบายตา และสี Teal/Emerald ประจำแบรนด์ยังเป็นหัวใจของอินเทอร์เฟซเหมือนเดิม
- **มุมโค้งสูงขึ้นทั่วทั้งเว็บ**
  สเกล radius ทั้งระบบถูกยกระดับ — การ์ด เมนู ไดอะล็อกและตัวควบคุมโค้งมนขึ้นชัดเจน (12–28px) ปุ่มและป้ายสถานะเป็นทรงแคปซูล pill ให้ความรู้สึกทันสมัยเป็นกันเองแบบแพลตฟอร์มชั้นนำ แต่ยังเป็น FanHoard 100%
- **เส้นขอบเบากว่า เงานุ่มกว่า**
  เส้นขอบเป็นสายหมึกบาง 8% เงาเบาและกระจายขึ้น พื้นผิวแยกกันด้วย contrast สะอาด ๆ แทนเส้นหนา
- **Motion มาตรฐานเดียว**
  transition ของอินเทอร์เฟซใช้ easing curve มาตรฐานเดียวกัน 150ms เร็ว / 250ms ปกติ และยังเคารพการตั้งค่า reduced-motion ของคุณเสมอ

### ปรับปรุง

- **Focus ring** สำหรับคีย์บอร์ดเปลี่ยนเป็นวงเรือง teal นุ่มขึ้นเล็กน้อย โดยคง contrast สูงเพื่อการนำทางด้วยคีย์บอร์ด

### ขั้นต่อไป

- ระบบนำทาง toast ป๊อปอัป ค้นหา Data Verse การตั้งค่า และทุกหน้าเนื้อหา จะถูก restyle ทีละระบบบนรากฐานใหม่นี้ — พร้อม release notes ของตัวเองทุกอัปเดต
