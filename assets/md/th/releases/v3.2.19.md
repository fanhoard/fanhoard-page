**TL;DR** — Data Verse (ฟีด discover และหน้า scope) เป็นระบบถัดไปที่ขึ้นรากฐานดีไซน์ใหม่ ไทล์อีโมจิและการ์ดฟีดใช้ภาษาการ์ดโค้งมนชุดเดียวกันพร้อมเงาลอยนุ่มตอน hover, สถานะ skeleton loading วิบวับบนพื้นกลางที่ถูกต้องทั้งสองธีม และสียุคเก่าตกค้าง (Material teal, เทา fallback เดิม) หายจากชั้น Data Verse ทั้งหมด

### ปรับปรุง

- **ไทล์และการ์ด discover** — ไทล์เนื้อหายืนยันมุมโค้ง 16px พร้อมขอบจางทั้งสองธีม; การ์ดฟีดลอยขึ้นด้วยเงานุ่มตอน hover แทนการสลับขอบเปล่า ๆ โดยเงามี transition เรียบร้อย
- **Focus ring รวมศูนย์** — ไทล์, การ์ด และ sub-nav pill ใช้ focus ring สี teal 3px มาตรฐานใหม่ทั่วทั้งฟีด
- **Skeleton shimmer** — placeholder ตอนโหลดใช้พื้นกลางที่ถูกต้องและมุมโค้ง 12px ดูดีทั้ง light และ dark
- **หน้า scope** — ผิวการ์ดตรวจสอบกับมาตรฐานการ์ดทั้งเว็บ (การ์ดชั้นเดียวโค้ง 24px ขอบจาง); สีตัวอักษรย้ายมาบนพาเลตต์ปัจจุบัน
- **จังหวะสม่ำเสมอ** — อนิเมชั่นโผล่ของเนื้อหา (กลุ่มและหน้า) ใช้ curve มาตรฐานเดียวกันทั้งเว็บ; พฤติกรรม reduced-motion ไม่เปลี่ยนและถูกเคารพครบ
- **สถานะ error** — ผิว render-error ใช้พาเลตต์ danger ปัจจุบันทั้งสองธีม

### แก้ไข

- **สีตกค้างยุคเก่า** — Material teal (#009688) และ fallback เทาแบนสุดท้ายใน bottom navigation, พื้น pill active และ scrollbar thumb แทนที่ด้วย token ปัจจุบันทั้ง light และ dark

### หมายเหตุ

- การวางตำแหน่งของ virtual list engine ไม่ถูกแตะ: อนิเมชั่นเข้าของการ์ดยังเป็น opacity-only บน wrapper ที่ถูกวางตำแหน่ง (กันซ้อน), ชุด e2e ของ discover และ scroll-lock test ยังเขียว ตรวจ responsive grid ใน browser จริงที่ 375/768/1280px ทั้งสองธีม (ปรับ 4→6 คอลัมน์)
