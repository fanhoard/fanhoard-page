**TL;DR** — สำเร็จภารกิจยกระดับระบบสุดท้าย (s10) ของ FanHoard ในส่วนหน้าชุมชนและหน้าแพลตฟอร์ม (`community/*`, `platform/*`, `home/index.html`): ปรับปรุง UX แบบฟอร์มแจ้งปัญหาพร้อมรองรับ A11y ด้วย `aria-invalid` และ `aria-describedby`, ย้ายโฟกัสไปยังช่องที่ไม่ถูกต้องอัตโนมัติ, ซิงก์สลับภาษาบนแบบฟอร์มแบบเรียลไทม์, แก้ไข Title tag หน้าชุมชน และอีเมลติดต่อทางการให้ถูกต้อง, เพิ่ม Focus Ring ความคมชัดสูงสำหรับคีย์บอร์ดบนหน้า Roadmap และ What's New พร้อมผ่านการทดสอบ E2E ทั้งหมด 15 รายการ

### การปรับปรุงหลัก

- **ยกระดับ UX และ A11y แบบฟอร์มแจ้งปัญหา (`community/report/index.html`)**
  ปรับปรุงระบบตรวจจับข้อผิดพลาดแบบฟอร์ม: ช่องที่กรอกไม่ถูกต้องจะตั้งค่า `aria-invalid="true"` และเชื่อม `aria-describedby` กับข้อความแจ้งเตือน เพื่อให้ Screen Reader อ่านข้อผิดพลาดได้อย่างถูกต้อง เมื่อกดส่งแบบฟอร์มไม่ผ่านระบบจะย้ายโฟกัสไปยังช่องแรกที่ต้องแก้ไขทันที พร้อมเพิ่ม Event Listener ตรวจจับการเปลี่ยนภาษาแบบเรียลไทม์ (`fv:langchange` และ `languageChange`)
- **ซิงก์ภาษาแบบฟอร์มติดต่อ (`community/contact/index.html`)**
  เพิ่ม Event Listener สลับภาษาตัวเลือกและข้อความปุ่มดำเนินการทันทีเมื่อผู้ใช้เปลี่ยนภาษาบนเว็บไซต์
- **ปรับปรุงหน้าเนื้อหาชุมชนและแพลตฟอร์ม**
  ปรับแก้ไข Title tag ของหน้า Community Hub เป็น `Community — FanHoard`, สะกดแก้ไขอีเมลติดต่อทางการในไฟล์แปลภาษา (`assets/lang/en.json`), เพิ่ม Focus Ring ความคมชัดสูง (`:focus-visible`) ใน `roadmap.css` และ `new.css` พร้อมตรวจสอบ Landmarks (Skip link, Main, Footer) สมบูรณ์ทุกหน้า
- **การทดสอบความเสถียรแบบครบวงจร**
  เพิ่มชุดทดสอบ `tests/community-platform-polish.test.ts` ตรวจสอบสถานะการทำงาน (ยูนิตเทสต์ผ่าน 234/234 เคสใน 37 ไฟล์) และผ่านการทดสอบ E2E Suite ฉบับเต็ม (`npx playwright test`) ผ่าน 15/15 เคส

### ความเสถียรและการทดสอบ

- เพิ่ม `tests/community-platform-polish.test.ts` ตรวจสอบความถูกต้องของ Landmarks, แบบฟอร์มรายงานปัญหา, การย้ายโฟกัส และความถูกต้องของข้อมูลแปล
- ผ่านการทดสอบ Playwright E2E Suite ครบ 15/15 รายการ
- ผ่านการสร้าง static site (`npm run build`)
