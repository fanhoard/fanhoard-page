**TL;DR** — ยกระดับหน้าการตั้งค่าของ FanHoard (`setting/index.html` และ `assets/js/setting-system/`) และเครื่องมือเสริมสู่มาตรฐานแพลตฟอร์มสูงสุด: เพิ่ม `ThemeCore` (`assets/js/setting-system/theme-core.js`) สลับและจำค่าธีมเว็บไซต์แบบไม่มีแสงกะพริบ (FOUC), พัฒนา `SettingUI` (`assets/js/setting-system/setting-ui.js`) ควบคุมสวิตช์และปุ่มตัวเลือกภาษาพร้อมระบบแจ้งเตือนการบันทึกทันที (`PopupSystem.toast.success`), เพิ่มสวิตช์เลือกธีมการแสดงผลบนหน้าการตั้งค่า, ปรับปรุง Focus Ring สำหรับคีย์บอร์ดให้คมชัดเด่นชัด และอัปเกรด `back-to-top.js` ให้เป็นปุ่มที่เข้าถึงได้ง่าย (A11y) และเคารพการตั้งค่า `prefers-reduced-motion`

### การปรับปรุงหลัก

- **ระบบสลับและจัดเก็บธีมกลาง (`ThemeCore`)**
  เพิ่ม `assets/js/setting-system/theme-core.js` สำหรับโหลดและเปลี่ยนธีมเว็บไซต์อย่างรวดเร็ว ซิงก์ค่าลง `localStorage` (`fv_theme` / `fv_preferences`) และ `PreferenceStore` พร้อมตรวจจับการตั้งค่าโหมดมืดของระบบปฏิบัติการ และปรับสลับธีมนุ่มนวลโดยไม่เกิดอาการวูบกะพริบ
- **ระบบควบคุมสวิตช์การตั้งค่า (`SettingUI`) และ Save Feedback Toast**
  เพิ่ม `assets/js/setting-system/setting-ui.js` ควบคุมสวิตช์เปลี่ยนธีม, สวิตช์อัปเดตอัตโนมัติ และตัวเลือกภาษา ทุกการสลับค่าการตั้งค่าจะแสดงข้อความยืนยันการบันทึกผ่าน `PopupSystem.toast.success` ทั้งภาษาไทยและอังกฤษ
- **ปรับปรุง UX หน้าการตั้งค่าและสวิตช์ธีมการแสดงผล**
  เพิ่มแถบสวิตช์ปรับธีมลงในหน้า `setting/index.html` ตกแต่งสไตล์ Unboxed Group สอดคล้องกับดีไซน์หลัก พร้อม Focus Ring ความคมชัดสูง (`#0d9488` / `#00FFAA`), กำหนด `role="switch"` และ `aria-checked` พร้อมรองรับคีย์บอร์ด (Space / Enter)
- **ปรับปรุงปุ่มกลับสู่ด้านบน (`back-to-top.js`)**
  อัปเกรด `assets/js/back-to-top.js` โดยระบุ `type="button"` ชัดเจน, ซิงก์ `aria-hidden` ตามการแสดงผล, รองรับคีย์บอร์ด และปรับความนุ่มนวลในการเลื่อนโดยเคารพค่า `prefers-reduced-motion`

### ความเสถียรและการทดสอบ

- เพิ่มชุดทดสอบ `tests/settings-polish.test.ts` ตรวจสอบฟังก์ชัน ThemeCore, การทำงานของ SettingUI, การแจ้งเตือน Toast และคุณสมบัติ A11y ของปุ่ม Back-to-top (ผ่านการทดสอบยูนิตเทสต์ 229/229 เคสใน 36 ไฟล์)
- ผ่านการทดสอบ Playwright e2e (`e2e/theme-toggle.spec.ts` และ `e2e/scroll-lock.spec.ts` 4/4 เคส)
- ผ่านการสร้าง static site (`npm run build`)
