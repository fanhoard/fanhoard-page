**TL;DR** — ป๊อปอัปและโมดัลเป็นระบบถัดไปที่สร้างใหม่บนรากฐานดีไซน์ใหม่ ทุกไดอะล็อก alert confirm และ bottom sheet เปิดด้วยมุมโค้ง 24px เงาลอยนุ่ม และปุ่มทรง pill และที่สำคัญที่สุด — ตรวจจับธีม light/dark ที่คุณเลือกไว้ (รวมค่าของระบบ) แล้วเปิดด้วยพาเลตต์ที่ตรงกันโดยอัตโนมัติ อัปเดตนี้ยังแก้บั๊กจริงที่ทำให้ข้อความในป๊อปอัปเป็นสีเข้มจนอ่านยากใน dark mode

### ใหม่

- **ป๊อปอัปตามธีมอัตโนมัติ** — ไดอะล็อก alert และ confirm ตรวจธีมปัจจุบันของเว็บ (รวมการตั้งค่าของระบบ) แล้วเปิดด้วยพาเลตต์ที่ตรง: การ์ดขาวขอบจางใน light, การ์ด slate เข้มใน dark

### แก้ไข

- **ตัวหนังสือ contrast ต่ำใน dark mode** — CSS ที่พังบล็อกหนึ่งแอบใส่สีเข้ม slate ให้ข้อความทุกป๊อปอัป ทำให้อ่านยากบนการ์ดเข้ม ตอนนี้กำหนดขอบเขตถูกต้องแล้ว
- **Ghost design token** — เอนจินธีมของป๊อปอัปอ้างถึง 5 token ที่ไม่เคยถูกกำหนด (เส้นขอบ ข้อความรอง หัวข้อ) ทำให้สไตล์เสียเงียบ ๆ ตอนนี้ชี้ token จริงครบ
- **พาเลตต์ dark ครั้งเก่า** — ป๊อปอัป dark เคยใช้น้ำเงินหม่นนอกพาเลตต์ (#1a1f2e) ตอนนี้ใช้พาเลตต์ dark ของเว็บพอดี (การ์ด slate-800, ข้อความ slate-50)

### ปรับปรุง

- **พื้นผิวโค้งมน 24px** พร้อมเงาลอยนุ่มและ scrim จาง แทนกล่องแบนเส้นบางเดิม
- **ปุ่ม pill** — ปุ่มใน footer ป๊อปอัปและปุ่มปิดเป็นทรงกลมเต็ม
- **เปิดลื่นขึ้น** — อนิเมชั่นเข้า/ออกมาตรฐาน 250ms ด้วย easing มาตรฐานเดียวกันทั้งเว็บ
- **Side drawer และ bottom sheet** — ขอบนำ 24px โค้งมน พื้น sheet รับธีม พร้อม grab handle ทรง pill

### หมายเหตุ

- อนิเมชั่นทั้งหมดเคารพ reduced-motion และพฤติกรรม scroll-lock ของ overlay ซ้อนกันผ่าน regression test ครบ
