**TL;DR** — การโหลดไม่บังหน้าเว็บอีกต่อไป ทุกหน้าที่เคยว่างเปล่าหลัง overlay เต็มจอ ตอนนี้วาด skeleton ตรงกับเลย์เอาต์จริงทันที แสดงเนื้อหาจริงแบบทยอยขึ้น ให้กดเมนูระหว่างโหลดได้ และรายงานสถานะการโหลดให้เทคโนโลยีช่วยอ่านถูกต้อง

### New

- **ระบบ Progressive Loading (PLSys)**
  เลเยอร์โหลดแบบ progress ทั้งเว็บ: state machine กำกับวงจรการโหลดแบบ deterministic, แคชแบบ stale-while-revalidate, timeout มีขอบเขตพร้อมปุ่มลองใหม่, skeleton เหมือนเรขาคณิตจริง (ไม่มี layout shift), รูปแบบ static สำหรับผู้ใช้ reduced-motion และ telemetry ผ่าน performance marks
- **Skeleton grid อบไว้ล่วงหน้าบน Discover**
  หน้า Discover ส่ง skeleton grid ที่สร้างจากฝั่งเซิร์ฟเวอร์มาใน HTML เลย ทำให้เลย์เอาต์วาดทันทีก่อนดาวน์โหลด dataset

### Improved

- **ไม่มี overlay บังหน้าอีกต่อไป**
  หน้าจอโหลดบูตบน Discover ถูกลบออกแล้ว skeleton แบบกำกับขอบเขตเนื้อหาและแถบ progress บางบนสุดให้ feedback โดยไม่บังหน้าหรือล็อกการใช้งาน
- **Search, Settings, Roadmap และ What's New โหลดแบบ progress**
  แต่ละหน้าวาด skeleton ในบริเวณของตัวเองระหว่างดึงข้อมูล ช่องกรอกและโฟกัสใช้งานได้ตลอด พร้อมปุ่มลองใหม่ในเครื่องเมื่อ fetch พลาด
- **การเข้าถึงระหว่างโหลด**
  container ที่กำลังโหลดรายงาน `aria-busy` ถูกต้องระหว่าง fetch และเคลียร์อย่างน่าเชื่อถือเมื่อเนื้อหาขึ้นจริง skeleton ถูกซ่อนจาก assistive tech และเปลี่ยนเป็น static เมื่อผู้ใช้เลือกลดการเคลื่อนไหว

### Fixed

- **เนื้อหาหมวดบน Discover ไม่ขึ้น**
  pipeline ของหมวด symbol/emoji/fancy อ่าน schema ดัชนีข้อมูลที่ไม่มีอยู่จริง และเรียก resolver ที่ไม่เคยถูกนิยาม ทำให้พื้นที่เนื้อหาว่างหลังเปลี่ยนหมวด ตอนนี้ทั้งคู่อ่านรูปแบบ dataset จริงแล้ว
- **สถานะ loading ค้างหลังเนื้อหาขึ้นแล้ว**
  id ของ loader ชนกันทำให้ scoped loader ไม่ทำงานหลังบูต และ flag busy ของ skeleton ที่อบไว้ไม่ถูกเคลียร์เมื่อเนื้อหาจริงขึ้น ตอนนี้ตัวบอกสถานะโหลดเริ่มและจบถูกต้องเสมอ
