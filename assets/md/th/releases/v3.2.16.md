**TL;DR** — การแจ้งเตือน feedback เป็นระบบถัดไปที่สร้างใหม่บนรากฐานดีไซน์ใหม่ toast Success/Error/Warning/Info และแคปซูล "คัดลอกแล้ว" เป็นทรง pill โค้งเต็มบนพื้นการ์ดที่รับธีม — ที่สำคัญที่สุดคือไม่เป็นกล่องขาว hardcoded ใน dark mode อีกต่อไป — และแต่ละชนิดมีจุดสถานะสีกำกับชัดเจน

### ใหม่

- **Toast ทรงแคปซูล** — การแจ้งเตือนทุกชนิดเป็น pill โค้งเต็มบนพื้นการ์ดที่รับธีม พร้อมเงานุ่ม ทั้งโหมดสว่างและมืด
- **จุดสถานะสี** — toast แต่ละชนิดมีจุดสีกำกับ: เขียวมรกตสำหรับสำเร็จ แดงสำหรับ error อำพันสำหรับ warning เขียวtealสำหรับ info อ่านโทนได้ในพริบตา

### แก้ไข

- **แคปซูล copy และ toast ใน dark mode** — องค์ประกอบเหล่านี้เคย hardcode พื้นขาวไม่สนธีม ตอนนี้รับธีมมืดถูกต้อง
- **การประกาศ warning** — toast แบบ warning ประกาศแบบ assertive ต่อ screen reader (เหมือน error) แทน polite เดิม

### ปรับปรุง

- **จังหวะลื่นขึ้น** — การเข้าฉากของ toast มาตรฐานเป็น 250ms ด้วย easing curve มาตรฐานเดียวกันทั้งเว็บ และความสุภาพต่อ screen reader ยังถูกต้องตามชนิด (polite สำหรับ info/success, assertive สำหรับ error/warning)

### หมายเหตุ

- อนิเมชั่น toast ทั้งหมดเคารพการตั้งค่า reduced-motion ของคุณ
