**TL;DR** — ยกระดับระบบป๊อปอัพ (Popup System: Dialog, Alert, Confirm, Bottom Sheet, Drawer, Toast, Tooltip, Popover และ Fullscreen Overlay) สู่มาตรฐานแพลตฟอร์มสูงสุด: ปรับแต่ง Timing และ Bezier Easing ให้สอดคล้องกันทุกรูปแบบ, ปรับปรุง Focus Trap และการค้นหา Element ที่โฟกัสได้, เพิ่มฟังก์ชันแจ้งเตือน Toast ตามสถานะ (`toast.success`, `toast.error`, `toast.warning`, `toast.info`), ปรับปรุงเงื่อนไขการปิดด้วยปุ่ม Escape และการคลิก Backdrop ไม่ให้ปิดผิดพลาดจากการลากคลุมข้อความ พร้อมเสริม ARIA live regions สำหรับ Screen Reader

### การปรับปรุงหลัก

- **Timing และ Bezier Easing ของ Animation ให้สอดคล้องกัน**
  ปรับระยะเวลาและ Transition Curve สำหรับการเปิดและปิดป๊อปอัพทุกประเภท (Dialog, Sheet, Drawer, Toast, Fullscreen) ให้สมูทสอดคล้องกันด้วย `cubic-bezier(0.4, 0, 0.2, 1)` ขณะแสดงผล และ `cubic-bezier(0.4, 0, 1, 1)` ขณะปิด
- **ยกระดับ Focus Trap และการจัดการโฟกัสคีย์บอร์ด**
  ปรับปรุงการค้นหา Element ภายใน Focus Trap โดยส่งออก `AUTO_FOCUS_SELECTOR` ใน `config.js` และกรอง Element ที่ถูกซ่อนหรือปิดใช้งานออก ช่วยให้การกด Tab และ Shift+Tab วนลูปโฟกัสภายในป๊อปอัพเป็นไปอย่างราบรื่น
- **รูปแบบแจ้งเตือน Toast ตามสถานะพร้อมแถบสีเน้นย้ำ**
  เพิ่ม Helper Methods สำหรับแจ้งเตือน Toast แยกตามสถานะ (`toast.success`, `toast.error`, `toast.warning`, `toast.info`) พร้อมแถบสีขอบเน้นย้ำตามสถานะ และส่งข้อมูลประกาศไปยัง Screen Reader อัตโนมัติ
- **ป้องกันการปิดผิดพลาดจากคีย์ Escape และการคลิก Backdrop**
  ปรับปรุงการประมวลผลคีย์ Escape ไม่ให้ปิดป๊อปอัพเมื่ออยู่ใน Widget อื่นที่ยกเลิก Event และปรับ Backdrop ให้ตรวจสอบตำแหน่ง `mousedown` เพื่อป้องกันการปิดป๊อปอัพโดยไม่ตั้งใจขณะลากคลุมข้อความ
- **การรองรับ Accessibility (A11y) และ Reduced Motion**
  เพิ่มคุณสมบัติ `aria-modal="true"`, `aria-live` และ `aria-atomic` สำหรับ Screen Reader, ปรับแต่งกรอบโฟกัส `:focus-visible` ความคมชัดสูง และรองรับ `@media (prefers-reduced-motion: reduce)` ปิด Animation อัตโนมัติ
