**TL;DR** — ยกระดับสถาปัตยกรรมระบบภาษาและการแปลภาษาของ FanHoard สู่มาตรฐานแพลตฟอร์มสูงสุด: ปรับปรุง Pop-up เลือกภาษา (`UIService.openLanguagePopup`) ให้มี ARIA Semantics (`listbox`/`option`), สัญลักษณ์เครื่องหมายถูก (`✓`) สำหรับภาษาที่ใช้งานอยู่, กรอบ Focus High-contrast, Transition ที่สมูทลื่นไหล และการสลับภาษาด้วยคีย์บอร์ด (`ArrowUp`/`ArrowDown`/`Enter`/`Space`), กำจัดโค้ด IIFE ซ้ำซ้อนใน `lang-core.js` ออกอย่างหมดจด, ซิงก์ระบบปรับ Prefix ลิงก์อัตโนมัติ (`lang-links.js`) ให้รองรับ `fv:langchange` Event และยกระดับ `TranslatorService` ให้สามารถจัดเก็บและคืนค่าโครงสร้าง HTML รวมถึง Attribute สำคัญ (`placeholder`, `title`, `aria-label`) เมื่อสลับกลับเป็นภาษาอังกฤษ

### การปรับปรุงหลัก

- **Pop-up เลือกภาษาที่ใช้งานง่ายและเข้าถึงได้ครอบคลุม (A11y)**
  อัปเกรดตัวเลือกภาษาใน `assets/js/lang-modules/ui.js` ให้เป็นองค์ประกอบ `<button type="button">` ที่อยู่ภายในคอนเทนเนอร์ `role="listbox"` พร้อมเพิ่ม `role="option"`, `aria-selected`, สัญลักษณ์เครื่องหมายถูก (`✓`), กรอบ Focus เส้นเด่นชัด (`outline: 2px solid #00FFAA`), Transition ที่นุ่มนวลขนาด 180ms และการควบคุมเลื่อนเลือกด้วยปุ่มลูกศรและปุ่ม Enter/Space
- **กำจัดโค้ดซ้ำซ้อนใน Central Language Core API (`lang-core.js`)**
  กำจัดโค้ด IIFE ที่ซ้ำซ้อนจำนวน 257 บรรทัดใน `assets/js/lang-core.js` ช่วยลดขนาดไฟล์สคริปต์ลงอย่างชัดเจน ในขณะที่ยังคงประสิทธิภาพการประมวลผลภาษาแบบ Synchronous (`window.FvLang`), การส่ง Custom Event (`fv:langchange`) และการซิงก์ค่าภาษาใน `localStorage`
- **ซิงก์ระบบจัดการ Prefix ภาษาบนลิงก์ภายใน (`lang-links.js`)**
  ปรับปรุง `lang-links.js` ให้รับฟังทั้ง `languageChange` และ `fv:langchange` Custom Event ช่วยให้ URL Prefix บนลิงก์ภายในและองค์ประกอบที่สร้างขึ้นใหม่ถูกอัปเดตอย่างแม่นยำในทุกรูปแบบการสลับภาษา
- **การจัดเก็บและคืนค่าโครงสร้าง HTML และ Attributes (`translator.js`)**
  ปรับปรุง `TranslatorService` (`storeOriginalContent` และ `resetToEnglishContent`) ให้รองรับการบันทึก `data-original-html`, `data-original-placeholder`, `data-original-title` และ `data-original-aria-label` ทำให้การสลับกลับเป็นภาษาอังกฤษคืนค่าองค์ประกอบย่อย ไอคอน สล็อต SVG และ Attribute ต่างๆ ได้อย่างสมบูรณ์แบบโดยไม่สูญเสียเลย์เอาต์
