**TL;DR** — ยกระดับหน้า Discover ของ Data Verse และ Universal Render Engine (URE) สู่มาตรฐานแพลตฟอร์มสูงสุด: ปรับแต่ง Animation โหลดแบบ Skeleton Shimmer ในระดับองค์ประกอบด้วย Gradient Token ที่รองรับ Light/Dark Mode, เพิ่ม Transition ปรากฏเนื้อหาขนาด 220ms แบบไม่กระทบโครงสร้างเลย์เอาต์ (CLS-safe), เพิ่มความสละสลวยในการสลับหมวดหมู่และการเลื่อนปุ่มให้อยู่กึ่งกลางหน้าจอพร้อมรองรับ `prefers-reduced-motion`, เพิ่มคุณสมบัติ Accessibility (`role="button"`, `tabindex="0"`, `type="button"`) สำหรับการ์ดและปุ่มที่มีปฏิสัมพันธ์ และปรับปรุงการนำ DOM Node กลับมาใช้ใหม่ (Pool Recycling) ให้สมบูรณ์แบบ

### การปรับปรุงหลัก

- **Skeleton Shimmer Animation & Theme Tokens**
  ปรับปรุง Animation โหลดแบบ Skeleton Shimmer ใน `ure.css` ให้ลื่นไหลด้วย Curve `cubic-bezier(0.4, 0, 0.6, 1)` ระยะเวลา 1.5 วินาที พร้อมปรับใช้ Gradient CSS Token (`--surface-hover`, `--border-subtle`) ที่กลมกลืนทั้งในธีมสว่างและธีมมืด
- **Content Appear Reveal Transition แบบ CLS-Safe**
  เพิ่ม Transition แสดงเนื้อหาใหม่ขนาด 220ms (`translateY(4px)` สู่ `0px` ร่วมกับ Opacity Fade) สำหรับ Feed Group และการ์ด URE ช่วยให้เนื้อหาทยอยปรากฏอย่างนุ่มนวลโดยไม่เกิด Layout Shift
- **ความลื่นไหลในการสลับหมวดหมู่และการรองรับ Reduced Motion**
  ปรับปรุง Transition ของ Sub-Nav และฟังก์ชันเลื่อนปุ่มให้อยู่กึ่งกลางหน้าจอ (`scrollActiveMainButtonIntoView`, `_scrollSub`) ให้สมูท พร้อมตรวจสอบการตั้งค่า `prefers-reduced-motion: reduce` เพื่อสลับไปใช้ Smooth/Auto Scroll ที่เหมาะสม
- **การรองรับ Accessibility (A11y) สำหรับการ์ดและปุ่ม**
  ปรับปรุง `DiscoverFeed.ts` ให้กำหนด `type="button"` บนปุ่มสัญลักษณ์ และกำหนด `role="button"`, `tabindex="0"`, `aria-label` บนการ์ดเนื้อหาที่มีลิงก์ พร้อมล้างค่า Attribute ต่างๆ อย่างสะอาดเมื่อนำ Node กลับเข้า Pool
- **คุณภาพการสลับสถานะจากการโหลดสู่เนื้อหาจริง**
  ปรับปรุงกระบวนการเคลียร์ Scoped Loader ใน `ContentService` (`_appendFeedGroups`, `clearContent`) ให้สอดคล้องกับ `aria-busy` และยกเลิก Timer สำรองอย่างถูกต้อง ป้องกันปัญหา Spinner ค้างหรือหน้าว่างกระพริบ
