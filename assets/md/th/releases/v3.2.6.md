**TL;DR** — ยกระดับระบบค้นหา (Search System: Overlay, แถบป้อนคำค้น, รายการคำแนะนำ, การควบคุมด้วยคีย์บอร์ด และ Virtual Scroll) สู่มาตรฐานแพลตฟอร์มสูงสุด: เพิ่ม Transition การเปิด/ปิด Overlay นุ่มนวล, ปรับปรุงการกดคีย์บอร์ดวนลูปแบบสองทาง (กด `ArrowDown` สู่คำแนะนำ, กด `ArrowUp` วนกลับสู่ช่องค้นหา), เพิ่มกรอบโฟกัส (Focus Ring) สำหรับรายการคำแนะนำ, เพิ่มระบบประกาศผลค้นหาสำหรับ Screen Reader อัตโนมัติ และทำความสะอาด Event Delegation

### การปรับปรุงหลัก

- **Transition เปิด/ปิด Overlay และรองรับธีมเข้ม**
  เพิ่มเอฟเฟกต์การจางและเลื่อนนุ่มนวล `180ms cubic-bezier(0.16, 1, 0.3, 1)` เมื่อเปิด/ปิด Overlay ค้นหา (`.search-overlay-active`) พร้อมปรับสีพื้นหลัง Overlay ให้ใช้ตัวแปร CSS (`var(--surface-base, #ffffff)`) รองรับโหมดมืดอัตโนมัติ
- **การนำทางคีย์บอร์ดและเน้นโฟกัสรายการคำแนะนำ**
  เพิ่มกรอบโฟกัส `:focus-visible` และสถานะ Hover สำหรับรายการคำแนะนำ พร้อมปรับให้การกด `ArrowUp` ที่รายการแรกสุดเลื่อนโฟกัสกลับไปยังช่องป้อนคำค้นหา และกด `ArrowDown` จากช่องป้อนคำค้นเข้าสู่รายการคำแนะนำอย่างสมบูรณ์
- **ระบบประกาศผลสำหรับ Screen Reader (A11y)**
  สร้างองค์ประกอบ `#searchLiveAnnouncer` แบบไดนามิกอัตโนมัติเพื่อประกาศจำนวนผลลัพธ์การค้นหาหรือสถานะค้นหาไม่พบไปยังโปรแกรมอ่านหน้าจอ (Screen Reader) แบบทันที
- **ทำความสะอาด Event Delegation ของแถบป้อนข้อมูล**
  ยกเลิกการทับซ้อนโปรแกรมจัดการ Event `onkeydown` บนช่องค้นหาขณะแสดงคำแนะนำ โดยรวบรวม Event คีย์บอร์ดทั้งหมดไว้ที่บริการ `input-bar` ส่วนกลาง
