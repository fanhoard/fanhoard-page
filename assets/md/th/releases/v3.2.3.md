**TL;DR** — ระบบหน้าโหลด, ป๊อปอัพ และแถบค้นหา ย้ายมาใช้ศูนย์กลางการล็อกการเลื่อนหน้าเว็บชุดเดียวกันแล้ว (Unified Scroll-Lock Core) ช่วยให้ Overlay ที่เปิดซ้อนกัน (เช่น ป๊อปอัพบนหน้าโหลดแบบเต็มจอ) ไม่ปลดล็อกหน้าเว็บด้านหลังโดยไม่ตั้งใจเมื่อปิดตัวใดตัวหนึ่ง พร้อมรักษาตำแหน่งการอ่านและการชดเชยขนาดแถบสกอร์บาร์ให้อย่างสมบูรณ์

### การปรับปรุงหลัก

- **ระบบล็อกการเลื่อนหน้าแบบรวมศูนย์ (Unified Scroll-Lock Core)**
  หน้าโหลด ป๊อปอัพ และหน้าต่างค้นหา เชื่อมต่อผ่านแกนกลาง `ScrollLockCore` ที่นับจำนวนอ้างอิง (Reference Counting) เมื่อมี Overlay เปิดซ้อนกันหลายตัว การปิด Overlay ตัวหนึ่งจะยังคงล็อกหน้าเว็บด้านหลังไว้อย่างถูกต้อง จนกว่า Overlay ทั้งหมดจะปิดลง
- **รองรับทุกหน้าและระบบสำรองแบบ Fail-Soft**
  แกนล็อกการเลื่อนทำงานได้ราบรื่นในทุกหน้าเว็บ แม้แต่หน้าเบาที่ไม่ใช้องค์ประกอบ FVL พร้อมระบบสำรองอัตโนมัติเพื่อให้ Overlay ทำงานได้ต่อเนื่องเสมอ
- **ตรึงตำแหน่งสกอร์บาร์และการเข้าถึง (Accessibility)**
  ตรึงตำแหน่งการอ่านของหน้าเว็บได้อย่างแม่นยำ ไม่เกิดอาการหน้ากระตุกด้วยระบบชดเชยความกว้างสกอร์บาร์ พร้อมรองรับการตั้งค่าลดการเคลื่อนไหว (reduced-motion)
- **ตรวจสอบสถานะได้ง่ายและ Hard Reset คืนค่าสมบูรณ์**
  แสดงสถานะการล็อกผ่าน Attribute `data-scroll-locked` บนองค์ประกอบ DOM เพื่อความสะดวกในการตรวจสอบ พร้อมฟังก์ชัน Hard Reset ที่คืนค่า Style ของ body และ html อย่างหมดจดเมื่อเกิดการรีเซ็ต

### ความเสถียรและการทดสอบ

- เพิ่ม Unit Contract Tests 8 เคสใน `tests/scroll-lock-core.test.ts` เพื่อตรวจสอบ Reference Counting, Owner Tags และการคืนค่า DOM
- เพิ่ม Playwright Real-Browser e2e Tests 3 เคสใน `e2e/scroll-lock.spec.ts` ครอบคลุมการล็อกหน้าโหลด, การทำงานซ้อนกันของ Overlay และการล็อก/ปลดล็อกของหน้าต่างค้นหา
