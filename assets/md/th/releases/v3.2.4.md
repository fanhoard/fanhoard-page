**TL;DR** — ยกระดับระบบไปป์ไลน์แจ้งเตือนอัปเดตเวอร์ชันสู่มาตรฐานสูงสุด: ป๊อปอัพแจ้งเตือนรองรับการแสดงผลวันที่ทั้งภาษาไทยและอังกฤษอย่างถูกต้อง มีระบบสำรองภาษาอังกฤษอัตโนมัติเมื่อใช้งานภาษาที่ไม่รองรับ ยกระดับการเข้าถึงสำหรับ Screen Reader (Modal A11y) และปรับปรุงให้สคริปต์ Dynamic Loader ทุกตัวได้รับ Build ID เพื่อล้างแคชอัตโนมัติเมื่อมีการปล่อยเวอร์ชันใหม่

### การปรับปรุงหลัก

- **ระบบสำรองภาษาและป้องกันข้อผิดพลาดเมื่อใช้ภาษาอื่น**
  `version-core.js` ตรวจสอบภาษาที่เลือกในระบบ (`en`, `th`) อย่างรัดกุมก่อนดึงไฟล์ บันทึกการอัปเดต พร้อมระบบสำรอง (Fallback) กลับสู่ภาษาอังกฤษอัตโนมัติหากไม่พบไฟล์หรือใช้งานในภาษาอื่น
- **การแสดงผลวันที่อัปเดตในป๊อปอัพ**
  แก้ไขฟังก์ชันแปลงรูปแบบวันที่ในป๊อปอัพแจ้งเตือนให้แสดงผลวันที่และเวลาตามรูปแบบท้องถิ่นอย่างถูกต้อง
- **ยกระดับการเข้าถึงสำหรับผู้ใช้ Screen Reader (Accessibility)**
  ปรับโครงสร้างข้อความหัวเรื่องป๊อปอัพเป็น `<h2>` พร้อมกำหนด `ariaLabel`, `ariaDescribedBy` และ Attribute `type="button"` สำหรับปุ่มกดอย่างครบถ้วน
- **ระบบ Cache-Busting สคริปต์ Dynamic Loader**
  แก้ไขสคริปต์ไปป์ไลน์ (`update-version.js`) ให้ใส่ Build ID ในไฟล์ Loader หลัก (`search.js` และ `fvl.js`) เพื่อล้างแคชสคริปต์ย่อยในเบราว์เซอร์อย่างสมบูรณ์ทุกครั้งที่มีการปล่อยเวอร์ชัน

### ความเสถียรและการทดสอบ

- เพิ่มชุดทดสอบ `tests/version-pipeline.test.ts` ตรวจสอบความถูกต้องของไฟล์ประวัติ, `index.json`, โครงสร้าง markdown และระบบป้องกันใน `version-core.js`
