**TL;DR** — ระบบค้นหาเป็นระบบถัดไปที่สร้างใหม่บนรากฐานดีไซน์ใหม่ การ์ดผลลัพธ์โค้งมน 16px ขอบจาง มีเงานุ่มตอนพักและลอยขึ้นเบา ๆ ตอน hover, ช่องค้นหาเป็นแคปซูลโค้งเต็ม และคำแนะนำใน overlay เป็นชิปโค้งมนพร้อม focus ring สไตล์ใหม่ สี teal ตกค้างจากยุคเก่า (เขียวtealแบบ Material) ถูกแทนที่ด้วยสีตัวตน teal/emerald ของ Fanhoard ครบทุกจุด

### ใหม่

- **ชิปคำแนะนำโค้งมน** — คำแนะนำใน search overlay เป็นชิปโค้งมน (12px) มีระยะห่างรอบขอบแทนแถวเต็มความกว้างแบบแบน พร้อม focus ring 3px ชัดเจนสำหรับการใช้คีย์บอร์ด

### ปรับปรุง

- **การ์ดผลลัพธ์** — มุมโค้ง 16px ขอบจาง เงานุ่มตอนพัก และ hover แล้วลอยขึ้นนุ่ม ๆ พร้อมขอบสีแบรนด์
- **แคปซูลค้นหา** — ช่องค้นหาคงทรงแคปซูลโค้งเต็ม พร้อม focus ring 3px แบบใหม่ (เดิมเป็นวงจาง 2px สี teal เก่า)
- **จังหวะสม่ำเสมอ** — transition ของ overlay และ header มาตรฐานตามเวลาทั้งเว็บ (150/250ms ด้วย curve มาตรฐาน)
- **ป้ายกำกับคำแนะนำ** — เป็น pill โค้งเต็ม; ป้ายชนิดใช้ตระกูลสีแบรนด์ teal แทนเขียวtealเก่า และอ่อนลงใน dark mode
- **Hover surface รวมศูนย์** — filter pill, ปุ่ม clear และ hover ของคำแนะนำใช้ hover surface token เดียวกันทั้ง light และ dark

### แก้ไข

- **สี teal ตกค้างนอกพาเลตต์** — ค่า hardcode 5 จุดของ Material teal เดิม (ตระกูล #009688) ใน focus ring, สี hover และ fallback แทนที่ด้วยสีแบรนด์ Fanhoard ทั้งสองธีม

### หมายเหตุ

- การ์ดซ้อนกันตอน refresh (regression เดิมของหน้านี้) ยังถูกเฝ้าระวังครบ: ตรวจการ์ดทุกใบใน browser จริงอยู่คนละตำแหน่ง และชุด regression test ยังเขียว อนิเมชั่นการเข้าของการ์ด URE ยังเป็น opacity-only ตามข้อกำหนด
