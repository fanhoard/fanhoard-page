**TL;DR** — ยกระดับระบบแจ้งเตือนเวอร์ชันใหม่ของ FanHoard สู่มาตรฐานแพลตฟอร์มสูงสุด: ปรับปรุง Focus Ring สำหรับคีย์บอร์ดและ Transition ที่ลื่นไหลใน `assets/js/version-core.js`, ยกระดับฟังก์ชัน `parseMD` ใน `version-core.js` และ `new.js` ให้จำแนกหัวข้อ Markdown (`### Key Improvements`, `### การปรับปรุงหลัก` ฯลฯ) ได้ทั้งภาษาไทยและอังกฤษ, ปรับแต่ง Key จัดเก็บสถานะ Dismiss ให้สอดคล้องกันทุกกรณี, ซิงก์การปิดแจ้งเตือนอัตโนมัติเมื่อเข้าหน้า `/platform/whats_new/` และปรับการแจ้งเตือนทั่วไปให้เป็นแบบ Non-blocking เพื่อไม่ให้รบกวนการใช้งานของผู้ใช้

### การปรับปรุงหลัก

- **ยกระดับตัวประมวลผล Markdown สำหรับหมายเหตุการอัปเดต (`parseMD`)**
  ปรับปรุงระบบอ่านหัวข้อใน `version-core.js` และ `assets/js/new.js` ให้จำแนกหมวดหมู่รายการอัปเดต (`new`, `improved`, `fixed`, `removed`) ด้วยคำสำคัญภาษาไทยและอังกฤษอย่างยืดหยุ่น แสดงรายการไฮไลต์และรายละเอียดการอัปเดตได้สมบูรณ์แบบ
- **ระบบจำสถานะ Dismiss และซิงก์หน้า มีอะไรใหม่**
  ปรับแต่ง Key การตรวจสอบและบันทึกสถานะการซ่อนแจ้งเตือน (`normVer`) ให้ตรงกันทุกจุด (`fv_dismissed_v3.2.10`) พร้อมซิงก์บันทึกสถานะเมื่อผู้ใช้กดปุ่ม "ดูรายละเอียด" หรือเข้าชมหน้า `/platform/whats_new/` ช่วยป้องกันการแจ้งเตือนซ้ำซ้อนในรอบการเข้าชมถัดไป
- **ปรับเปลี่ยนรูปแบบแจ้งเตือนทั่วไปเป็น Non-blocking**
  ปรับคอนฟิก Pop-up แจ้งเตือนอัปเดตทั่วไปให้เป็นแบบ Non-blocking (`blocking: false` โดยเริ่มต้น) ผู้ใช้สามารถคลิกพื้นหลังหรือกดปุ่ม ESC เพื่อปิดแจ้งเตือนได้ทันทีโดยไม่ถูกล็อกหน้าจอ
- **Focus Ring คมชัดเด่นชัดและ Transition ที่นุ่มนวล**
  เพิ่มดีไซน์ `:focus-visible` ความคมชัดสูง (`#13b47f` สำหรับ Light Mode และ `#00FFAA` สำหรับ Dark Mode) พร้อม Transition นุ่มนวลขนาด `0.18s cubic-bezier`

### ความเสถียรและการทดสอบ

- เพิ่มชุดทดสอบ `tests/version-notification-polish.test.ts` เพื่อตรวจสอบการประมวลผล Markdown, การตั้งค่า `blocking`, การจัดการ Version Key และการออกแบบ A11y (ผ่านการทดสอบยูนิตเทสต์ 215/215 เคสใน 34 ไฟล์)
- ผ่านการทดสอบ Playwright e2e (`e2e/scroll-lock.spec.ts` 3/3 เคส)
