**TL;DR** — เข้าเว็บที่ root ("/") จะ redirect ไปหน้า /home/ ทันทีแทนที่จะเจอหน้า 404 ส่วน path อื่นที่ไม่มีจริงยังแสดงหน้า 404 แบบเดิมทุกประการ

### เปลี่ยนแปลง

- **Root redirect** — "/" redirect ไป /home/ (302 ชั่วคราว) เปิดเว็บเข้าสู่หน้าแรกจริงเสมอ
- **พฤติกรรม 404 คงเดิม** — path อื่นที่ไม่มีจริงยังแสดงหน้า 404 อธิบายพร้อมลิงก์กลับบ้านเหมือนเดิมทุกอย่าง
