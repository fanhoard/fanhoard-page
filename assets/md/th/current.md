**TL;DR** — หน้าเว็บหลัง loading เต็มจอถูกล็อคจริงๆ ตลอดช่วงที่ overlay แสดง และปลดล็อคกลับมาปกติเมื่อมันหายไป แก้ที่ต้นเหตุพร้อมตาข่าย CSS กันอาการกลับมา

### แก้ไข

- **ล็อคเลื่อนจริง** — พื้นหลังเลื่อนทะลุหลัง loading เต็มจอไม่ได้อีกตลอดช่วงที่ overlay ยังแสดงอยู่ รวมถึงช่วงหน่วงก่อน overlay จางหาย
- **ผู้ล็อคเดียวเท่านั้น** — การนำทางหน้าเว็บไม่ลบ style ล็อคของหน้ากระดาษตรงๆ อีกต่อไป ทุก lock/unlock ผ่าน ScrollLockCore ตัวเดียวกัน ทำให้ popup, ค้นหา และ loading ไม่ปลดล็อคกันเอง
- **ตาข่าย CSS** — มี backstop ล็อคหน้าเอาไว้ทุกครั้งที่สถานะล็อคทำงาน แม้ script จะพลาดจน style หาย
- **กู้คืนตอน error** — หน้าเว็บโหลดไม่สำเร็จ หน้า error จะปลดล็อคก่อนแสดงเสมอ หน้าจะไม่ค้างเบี้ยวหลัง overlay อีก
