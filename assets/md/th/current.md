**สรุปสั้น** — หน้าหลักปรับเปลี่ยนมาใช้การ์ดมุมมน 28px แผงควบคุม 32px และปุ่มทรงแคปซูล (pill buttons) ตามดีไซน์โทเค็นใหม่ โดยโครงสร้าง HTML และเค้าโครงการจัดวางหน้าหลักยังคงเหมือนเดิม

### สิ่งที่เปลี่ยนแปลง

- **การ์ดมนขึ้นในหน้าหลัก** — อัปเดตการ์ดในหน้าหลักให้ใช้ดีไซน์โทเค็นมุมมนขนาด 28px
- **แผงควบคุมและปุ่มทรงแคปซูล** — ปรับใช้มุมมน 32px สำหรับแผงควบคุม และรูปทรงแคปซูลสำหรับปุ่มบนหน้าหลัก
- **โครงสร้าง HTML คงเดิม** — โครงสร้างเค้าโครงการจัดวาง เมนูนำทาง พฤติกรรม hover/active และคีย์บอร์ดชอร์ตคัตยังคงเหมือนเดิมทุกประการ
