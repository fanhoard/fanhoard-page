**TL;DR** — เว็บเปลี่ยนชื่อใหม่เป็น FanHoard ดีไซน์ทุกหน้าถูกปรับใหม่ให้ดูสม่ำเสมอและคมขึ้น การเลื่อนไป-กลับทำงานเหมือนแอปจริง และระบบค้นหาเร็วขึ้นกว่า 5 เท่าพร้อมแก้จุดอ่อนด้านความเสถียรไป 20 จุด

### New

- **ชื่อใหม่: Fantrove กลายเป็น FanHoard**
  ตั้งแต่วันนี้เว็บของเรามีชื่อใหม่ว่า FanHoard (แฟนฮอร์ด) ทุกอย่างยังเหมือนเดิมทุกอย่าง อีโมจิเหมือนเดิม ลิงก์ที่เคยเก็บไว้ยังใช้ได้ และของที่คัดลอกไว้ในเครื่องก็ยังอยู่ครบ เปลี่ยนแค่ชื่อหน้าปกเท่านั้น

- **ดีไซน์ใหม่ทั้งเว็บ บนระบบเดียวกันทุกหน้า**
  ปรับพื้นฐานระบบดีไซน์ใหม่ทั้งหมด แล้วไล่ขัดทุกหน้าให้มาอยู่บนมาตรฐานเดียวกัน ตั้งแต่หน้าแรก ฟีดสำรวจ ค้นหา ตั้งค่า หน้าชุมชน จนถึงหน้า 404 สีและคอนทราสต์อ่านง่ายขึ้นตามมาตรฐาน WCAG AA ส่วนหน้าต่างป๊อปอัป dialog และ toast ก็ออกแบบใหม่ให้ดูทันสมัยกว่าเดิม

- **เลื่อนไป-เลื่อนกลับแบบแอปจริง**
  กดกลับ (หรือสวอยป์ย้อน) แล้วหน้าจะจำตำแหน่งที่คุณเลื่อนค้างไว้ กลับมาแล้วเห็นของเดิมที่เดิม ไม่เด้งขึ้นบนสุดทุกครั้ง ส่วนการรีเฟรชจะพาคุณขึ้นบนสุดตามที่ควรจะเป็น

- **โหลดเฉพาะจุด ไม่กระพริบทั้งจอ**
  เดิมทีทุกการเปลี่ยนหน้าจะมีโหลดดิ้งเต็มจอเด้งสองรอบ ตอนนี้ตัวโหลดจะแสดงเฉพาะพื้นที่เนื้อหาที่กำลังโหลดจริงๆ เปิดหน้าครั้งแรกก็โหลดต่อเนื่องจากจอโหลดสู่เนื้อหาโดยไม่มีแฟลชเด้งเพิ่ม

### Improved

- **ค้นหาเร็วขึ้นกว่า 5 เท่า**
  พิมพ์ซ้ำคำเดิมตอบภายในไม่ถึง 0.1 มิลลิวินาที (จากเดิม 42 มิลลิวินาที) ด้วยแคชผลลัพธ์แบบใหม่ ส่วนคำค้นหาใหม่ก็เร็วขึ้นราว 5 เท่าด้วยระบบดัชนีค้นหาแบบ bucket ที่สแกนเฉพาะตัวเลือกที่เป็นไปได้ และตอบสนองตอนพิมพ์เร็วขึ้นอีก 30-50 มิลลิวินาที

- **ฟีดสำรวจจัดหนาแน่นขึ้น**
  จัด grid ใหม่ให้เห็นของเยอะขึ้นต่อจอทุกขนาด แก้ช่องว่างผีในกลุ่มหมวด และปุ่มทั้งหน้าสำรวจสม่ำเสมอกันหมด

- **แจ้งอัปเดตเด้งครั้งเดียวต่อเวอร์ชั่น**
  เห็นข่าวอัปเดตครั้งเดียว ปิดไปแล้วเงียบสนิท ไม่เด้งซ้ำทุกหน้า

### Fixed

- **จุดอ่อนด้านความเสถียร 20 จุด**
  รื้อตรวจสอบระบบค้นหาและฟีดสำรวจแบบละเอียด แก้การรั่วของหน่วยความจำ listener ที่สะสมไม่ถูกลบ และการจัดการ error ที่เงียบจนมองไม่เห็นปัญหา ตอนนี้ error ระหว่างใช้งานบน console เป็นศูนย์

- **ป๊อปอัปค้างเมื่อกดเปิด-ปิดเร็วๆ**
  แก้อาการ freeze ตอนสลับเปิด-ปิดป๊อปอัปติดๆ กัน พร้อม state ที่เคย desync ตามมา

- **accessibility ครบมาตรฐาน WCAG 2.2**
  หน้าหลัก หน้าสำรวจ และหน้าค้นหาผ่านการตรวจสอบด้วย axe-core ด้วยคะแนนเต็ม ศูนย์ข้อผิดพลาด เพิ่มบทบาท combobox และ listbox ให้ช่องค้นหา และโฟกัสกลับมาที่ช่องพิมพ์เมื่อปิดหน้าต่างแนะนำ
