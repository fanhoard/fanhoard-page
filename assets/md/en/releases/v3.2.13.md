**TL;DR** — Two fixes requested from real-browser feedback: (1) on the Search page, only the topmost result card was visible because the new appear transition animated `transform` on URE virtual-scroll wrappers, overriding the engine's inline positioning and stacking all cards at the same spot — wrappers now fade opacity only, and every result renders in its own position again; (2) the original premium dynamic `.active` animation on the main navigation buttons (the springy underline overshoot) is restored, and category pills no longer permanently shrink while selected. Added an E2E regression guard so stacked cards can never slip through again.

### Fixed

- **Search Results Rendering (`assets/js/ure/ure.css`)**
  The URE virtual scroll engine positions every result-card wrapper with an inline `transform` (see `virtual-list.js`). The content-appear animation introduced in v3.2.8 also animated `transform` on `.ure-visible` wrappers, and CSS animations override inline styles — so every card in the first window rendered at `translateY(0)` and stacked on top of each other, leaving only the topmost card visible. URE wrappers now use a dedicated opacity-only fade (`ure-appear-fade`) that never touches the engine's positioning; in-flow content groups (`.cm-group`, `.feed-page`) keep the original smooth appear.
- **Original Active-Button Animation Restored (`assets/css/nav-core.css`, `nav-core-ext.css`)**
  Brought back the original premium dynamic active indicator on the main navigation buttons: the underline now eases in with `200ms ease-in` and springs out with the designed `400ms cubic-bezier(0.34, 1.56, 0.64, 1)` overshoot curve. Category pill buttons (`.button-sub`) no longer carry a permanent `scale(0.97)` shrink while in the selected `.active` state — the shrink now applies only to the momentary `:active` press.

### Verified

- **New E2E regression guard** — `e2e/search-refresh-regression.spec.ts` now asserts result cards render at distinct positions (no transform-override stacking); this test fails on the broken state and passes after the fix.
- Unit tests 234/234 green (37 files) and full Playwright E2E suite 16/16 passing, including scroll-lock 3/3.
- Verified effective DOM state in a real browser: all 12 first-window search cards render at unique positions and are visible; discover feed groups render in normal flow at correct offsets.
