**TL;DR** — A wrong address in the report system pointed at a server that no longer exists, so sending a report failed with a "check your internet connection" message. It now reaches the live backend and sends correctly.

### Fixed

- **Community reports can be sent again**
  The report form was calling a backend address that does not exist anymore, so every submission failed with a "please check your internet connection" error even when your connection was fine. The form now sends to the live community backend, and reports go through again.

- **Community contact and report pages connect to the live service**
  All community pages now use the same working backend address, so the whole community section — not just the report form — is back in service.
