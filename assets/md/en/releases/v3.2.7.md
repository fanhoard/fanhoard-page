**TL;DR** — Elevates the Popup System (dialogs, alerts, confirms, bottom sheets, drawers, toasts, tooltips, popovers, and full-screen overlays) to top-platform standards: refined animation timing and cubic-bezier easing consistency, fixed focus trap interactive element resolution, added toast notification status variants (`toast.success`, `toast.error`, `toast.warning`, `toast.info`), enforced explicit Escape key and drag-release backdrop close rules, and added accessibility ARIA live regions and modal attributes.

### Key Improvements

- **Animation Timing & Preset Easing Consistency**
  Aligned open and close animation durations and transition curves across all popup presets (dialog, sheet, drawer, toast, fullscreen) with smooth `cubic-bezier(0.4, 0, 0.2, 1)` enter and `cubic-bezier(0.4, 0, 1, 1)` exit transitions.
- **Hardened Focus Trap & Keyboard Focus Management**
  Fixed focus trap element resolution by exporting `AUTO_FOCUS_SELECTOR` in `config.js` and filtering hidden/disabled elements, enabling smooth Tab and Shift+Tab focus wraparound across all interactive controls (including header close buttons).
- **Toast Status Variants & Visual Accents**
  Introduced typed toast notification helper methods (`toast.success`, `toast.error`, `toast.warning`, `toast.info`) with custom status border accents and live announcer screen reader feedback.
- **ESC Key & Overlay Click Protection**
  Hardened Escape key handling to ignore default-prevented widget keypresses, and updated backdrop clicks to track `mousedown` targets so text selection dragging inside popups does not trigger accidental backdrop dismissal.
- **Accessibility & Reduced Motion Enforcement**
  Added `aria-modal="true"`, `aria-live` and `aria-atomic` status attributes for screen readers, high-contrast `:focus-visible` ring styling, and explicit `@media (prefers-reduced-motion: reduce)` zero-animation overrides.

- Passed full Playwright e2e test suite (15/15 passed), including `scroll-lock.spec.ts` (3/3 passed).
