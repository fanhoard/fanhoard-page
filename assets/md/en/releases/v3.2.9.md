**TL;DR** — Elevates the FanHoard localization architecture to top-platform standards: refined the language picker popup (`UIService.openLanguagePopup`) with proper ARIA `listbox`/`option` semantics, active checkmark badges, focus rings, and keyboard navigation (`ArrowUp`/`ArrowDown`/`Enter`/`Space`), surgically removed a duplicate IIFE implementation in `lang-core.js`, synchronized `lang-links.js` with `fv:langchange` custom events, and hardened `TranslatorService` to store and restore original HTML structure and element attributes (`placeholder`, `title`, `aria-label`).

### Key Improvements

- **Accessible & Polished Language Picker Overlay UX**
  Upgraded language selection option elements in `assets/js/lang-modules/ui.js` to semantic `<button type="button">` elements inside a `role="listbox"` container. Added `role="option"`, `aria-selected`, active checkmark indicators (`✓`), high-contrast focus rings (`outline: 2px solid #00FFAA`), smooth 180ms cubic-bezier transition curves, and full keyboard arrow/enter navigation within the dialog.
- **Deduplicated Central Language Core API (`lang-core.js`)**
  Surgically removed 257 lines of duplicate IIFE code in `assets/js/lang-core.js`, reducing script bundle size while maintaining instant synchronous language resolution (`window.FvLang`), event listener dispatching (`fv:langchange`), and `localStorage` preference synchronization.
- **Synchronized Smart Link Language Prefix Manager (`lang-links.js`)**
  Updated `lang-links.js` to listen to both `languageChange` and `fv:langchange` global events, ensuring internal link hrefs and dynamic DOM mutations maintain accurate language prefixes across all interaction pathways.
- **Preserved HTML Structure & Attribute Restoration (`translator.js`)**
  Enhanced `TranslatorService` (`storeOriginalContent` and `resetToEnglishContent`) to store `data-original-html`, `data-original-placeholder`, `data-original-title`, and `data-original-aria-label`. Resetting to English now accurately restores child elements, icons, SVG slots, and translatable input attributes without layout degradation or content loss.

### Reliability & Verification

- Created unit test suite `tests/localization-polish.test.ts` verifying central API event dispatching, option markup semantics, keyboard focus, and content restoration (215/215 unit tests green across 34 test files).
- Verified Playwright e2e test suite (`e2e/language-switch.spec.ts` and `e2e/scroll-lock.spec.ts` all green).
