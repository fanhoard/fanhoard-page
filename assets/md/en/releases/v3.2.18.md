**TL;DR** — Search is the next system rebuilt on the new design foundation. Result cards are now cleanly rounded (16px) with subtle borders and a soft hover lift, the search input is a true capsule, and suggestions in the search overlay are rounded chips with a modern focus ring. Every remaining off-palette teal (the old Material-era green-teal) has been replaced with the Fanhoard teal/emerald identity.

### New

- **Rounded suggestion chips** — suggestions in the search overlay now render as rounded chips (12px) with inset padding instead of flat full-width rows, with a crisp 3px focus ring for keyboard navigation.

### Improved

- **Result cards** — 16px rounded corners, subtle border, resting soft shadow, and on hover a gentle elevation with the brand-tinted border.
- **Search capsule** — the search pill keeps its fully-rounded capsule shape with the new 3px focus ring (previously a faint 2px ring in the old teal).
- **Consistent motion** — overlay and header transitions standardized to the site-wide timing (150/250ms with the standard easing curve).
- **Suggestion badges** — fully rounded pills; type badges now use the brand teal family instead of the old green-teal, with a lighter teal in dark mode.
- **Unified hover surfaces** — filter pills, clear button and suggestion hover all use the same subtle hover surface token across light and dark.

### Fixed

- **Off-palette teal leftovers** — five hardcoded values of the old Material teal (#009688 family) in focus rings, hover tints and fallbacks replaced with the Fanhoard brand teal, in both light and dark themes.

### Notes

- Card stacking on refresh (the regression this page once had) remains fully guarded: all result cards verified at distinct positions in a real browser, and the regression suite stays green. URE card entry animation remains opacity-only as required.
