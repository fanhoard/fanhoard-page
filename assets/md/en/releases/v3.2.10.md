**TL;DR** — Elevates FanHoard user-facing update notifications to top-platform standards: refined modal focus ring contrast and smooth transitions in `assets/js/version-core.js`, upgraded `parseMD` in `version-core.js` and `new.js` to dynamically classify section headings (`### Key Improvements`, `### การปรับปรุงหลัก`, etc.) in EN and TH, normalized `v`-prefixed version strings for dismissal state persistence (`localStorage`), auto-dismissed versions when viewing `/platform/whats_new/`, and made routine release notifications non-blocking.

### Key Improvements

- **Hardened Multi-language Markdown Section Heading Parser (`parseMD`)**
  Upgraded section heading parsing in `version-core.js` and `assets/js/new.js` to dynamically classify section types (`new`, `improved`, `fixed`, `removed`) based on localized keyword matching instead of rigid exact string matches (`### New`, etc.). Full release note lists and item descriptions now render flawlessly across EN and TH.
- **Normalized Version Key Persistence & Auto-Dismissal**
  Normalized version string lookup keys (`normVer`) across `isDismissed`, `setDismissed`, and `isSessionFresh` (`fv_dismissed_v3.2.10`). Clicking "See what's new" or viewing `/platform/whats_new/` now records dismissal automatically so users are not nagged again on subsequent visits.
- **Non-blocking Routine Update Notification Decision**
  Updated default update notification modals to be non-blocking (`blocking: false` by default, configurable via frontmatter `blocking: true`). Users can click the backdrop or press ESC to dismiss routine release popups without interrupting their page flow.
- **Accessible Focus Rings & Silky Transitions**
  Enhanced modal button styling with high-contrast `:focus-visible` focus rings (`#13b47f` in light mode, `#00FFAA` in dark mode) and smooth `0.18s cubic-bezier` easing curves for action buttons.

### Reliability & Verification

- Created automated test suite `tests/version-notification-polish.test.ts` verifying markdown section classification, frontmatter `blocking` parsing, `normVer` string handling, and a11y styling (215/215 unit tests green across 34 files).
- Verified Playwright e2e test suite (`e2e/scroll-lock.spec.ts` 3/3 passed).
