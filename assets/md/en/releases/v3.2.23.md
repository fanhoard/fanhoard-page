**TL;DR** — The five platform pages now match the rest of the redesigned site: comfortable reading rhythm on the white canvas, themed teal accents in both modes, pill version badges and a softer, consistent focus ring.

### Improved

- **Brand teal everywhere** — page headings, links and accents on About, License, Privacy and Roadmap now use the current FanHoard teal in both light and dark mode.
- **What's New release cards** — version badges and time chips are pill-shaped with a soft teal tint; past releases fade gently below the current one.
- **Roadmap timeline** — feature dots and hairline separators use the subtle v3 borders, with themed grays instead of harsh blacks.
- **Focus rings** — keyboard focus across all five pages uses the site-wide 3px teal ring.

### Fixed

- **Update notes modal** — release notes are now written in the format the in-app update dialog parses, so every release shows its full item list instead of an empty one.
