**TL;DR** — Elevates the FanHoard settings system (`setting/index.html` and `assets/js/setting-system/`) and page utilities to top-platform standards: introduced `ThemeCore` (`assets/js/setting-system/theme-core.js`) for seamless site-wide theme switching and persistence without flash, created `SettingUI` (`assets/js/setting-system/setting-ui.js`) to orchestrate settings controls with instant save feedback toasts (`PopupSystem.toast.success`), added Appearance Theme switch control row to Settings, polished high-contrast focus rings and toggle transitions, and upgraded `back-to-top.js` utility with proper button semantics (`type="button"`), ARIA accessibility attributes, and `prefers-reduced-motion` compliance.

### Key Improvements

- **Unified Site-wide Theme & Persistence Core (`ThemeCore`)**
  Created `assets/js/setting-system/theme-core.js` providing synchronous early theme initialization, localStorage (`fv_theme` / `fv_preferences`) and `PreferenceStore` synchronization, system color scheme listeners (`prefers-color-scheme`), and smooth theme transitions without FOUC (flash of unstyled content).
- **Settings Page Control Orchestrator (`SettingUI`) & Save Feedback Toasts**
  Created `assets/js/setting-system/setting-ui.js` providing integrated control management for Appearance Theme switch, Auto-Update toggle, and Interface Language selector. All setting changes now trigger immediate user save feedback toasts via `PopupSystem.toast.success` in EN and TH.
- **Settings Page UX & Appearance Theme Control**
  Added Appearance Theme toggle row to `setting/index.html` with unboxed group styling, high-contrast focus rings (`#0d9488` / `#00FFAA`), `role="switch"`, `aria-checked` state updates, and keyboard control support (Space / Enter).
- **Accessible & Smooth Back-to-Top Page Utility (`back-to-top.js`)**
  Upgraded `assets/js/back-to-top.js` with explicit `type="button"`, dynamic `aria-hidden` attribute management, keyboard navigation (Space / Enter), and automatic smooth/instant scroll behavior respecting `prefers-reduced-motion`.

### Reliability & Verification

- Created automated test suite `tests/settings-polish.test.ts` verifying ThemeCore get/set/toggle/events, SettingUI toggle handlers, save toasts, and back-to-top accessibility (229/229 unit tests green across 36 test files).
- Verified Playwright e2e test suite (`e2e/theme-toggle.spec.ts` and `e2e/scroll-lock.spec.ts` 4/4 passed).
- Built cleanly with Vite + SSG (`npm run build`).
