พิสูจน์ว่าเกณฑ์ระดับระบบทั้ง 5 ข้อในแผนหลักผ่านบนเว็บจริงทั้ง 14 หน้า

2. ปัญหาเดิมที่ยังไม่แก้ทั้งหมดถูกรายงานตามจริง ไม่ปิดบัง
3. Master อนุมัติ

### แก้ในรอบตรวจรวมนี้
- ป้ายแท็บที่เลือกในแถบเมนูล่าง ธีมมืด 2.89 เป็น 8.23:1 และป้าย "Previous releases" ธีมมืด 3.35 เป็น 9.52:1 (สีตายตัวเปลี่ยนเป็นโทเค็น `--color-brand-text`) ปล่อยเป็น v5.11.2

### ปัญหาเดิมที่ยังไม่แก้ (รายงานตามจริง)
1. **กล่องแดงเปลี่ยนภาษาล้มเหลว** ระบบแปลภาษาสร้าง Web Worker จาก blob แต่ CSP (`script-src` ไม่มี `blob:` ไม่มี `worker-src`) บล็อก กล่องแดงขึ้นราว 3 วินาทีเมื่อเข้าด้วย URL ไม่มี prefix ภาษา (เช่น `/setting/`) ไม่ขึ้นเมื่อเข้า `/en/...` หรือ `/th/...` ตรงๆ เกิดบนเว็บจริง main ด้วย จึงไม่ได้เกิดจากรีดีไซน์ ทางแก้มี 2 ทาง (เพิ่ม `worker-src blob:` ใน CSP หรือให้ระบบแปลทำงานโดยไม่ใช้ worker เมื่อสร้างไม่ได้) ต้องให้ Master เลือก เพราะแตะความปลอดภัยของเว็บ
2. **ทางลัดเปลี่ยนภาษาบน URL ไม่มี prefix** หน้าไทยที่มาจาก redirect ได้ข้อความไทยเพียงบางส่วน (195 ถึง 240 ตัวอักษร เทียบกับ 559 เมื่อเข้า `/th/...` ตรงๆ) เกี่ยวข้องกับข้อ 1
3. **รุ่น 5.8.1 ถึง 5.10.0 ปล่อยโดยไม่มีป๊อปอัป** ตั้ง `notify: false` ผิดนโยบาย และมี `date:` ที่พิมพ์เอง แก้แล้วใน v5.11.0 ถึง v5.11.1 แต่ผู้ใช้ที่เข้าเว็บช่วงนั้นไม่เห็นป๊อปอัปของรุ่นเหล่านั้น
4. **ประวัติรุ่นเก่า (2.x ถึง 3.2.x) มีเวลาไม่ตรง commit จริง** เกิดจากเวลา build ของ CI ไม่แก้ย้อนหลัง
5. **ลิงก์ Google Form ในหน้าติดต่อเป็นข้อความตัวอย่าง** (`1FAIpQLSe_en_contact_form_url`) ต้องใช้ลิงก์จริงจาก Master
6. **เทสต์หน่วยตก 1 ข้อ** `version.json` ตามหลัง `current.md` เพราะ CI สร้างไฟล์นี้และ develop ไม่มี workflow ซิงก์

### สิ่งที่ตัวตรวจเดิมวัดผิดและแก้แล้ว (บันทึกไว้กันซ้ำ)
- พื้นหลังโปร่งใสทำให้ contrast ออกมา 1.00 ต้องผสมสีพื้นจริงแบบ alpha
- ตัวกรองแบบแท็บข้อความมีรัศมี 0 โดยตั้งใจ (Master ตัดสิน v5.9.0) ไม่นับเป็นปุ่มเหลี่ยม
- หน้า `/` คือหน้า 404 แบบกำหนดเองโดยออกแบบ (`_redirects`) วัด contrast แยก
- h1 ของ Setting, Home, What's New เป็น `fv-sr-only` ขนาดที่วัดได้ไม่ใช่ขนาดที่ผู้ใช้เห็น

### ต้องการให้ Master ตัดสิน
- เกณฑ์ข้อ 1 ถือว่าผ่านโดยยอมรับว่า Settings, ชุมชน และแพลตฟอร์มคงสภาพเรียบ (ตามแนวทาง S4 และ S5 ที่ตกลงไว้) หรือต้องให้ทั้ง 12 หน้าโหลดระบบกลางเพิ่ม
- ทางแก้กล่องแดงเปลี่ยนภาษา (ปัญหาเดิมข้อ 1)
- ลิงก์ Google Form จริง
- สถานะการปล่อย: ยังไม่ปล่อยตามคำสั่ง ขึ้น main ได้เฉพาะระบบอัปเดต
