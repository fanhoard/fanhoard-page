# Design Core — แผนระบบดีไซน์กลางใหม่ทั้งเว็บ

กฎของไฟล์นี้: ห้ามมีวิธีทำ ห้ามมีโค้ด มีเพียง ขั้น เป้าหมาย ผลลัพธ์ที่ตรวจได้ สถานะ และการตัดสินที่ผ่านการซักถามแล้ว

## หลักการของแผน

- ยึด ArchiveTune เป็นมาตรฐานภาพ: โครงเลย์เอาต์ ระยะห่างกว้าง ความโค้งสูง แคปซูล ความรู้สึก native app
- สีหลักยังเป็นเขียวตามอัตลักษณ์ fanhoard เปลี่ยนโทนเป็น Emerald Fresh สดใสขึ้น ดีไซน์ส่งเสริมความคิดสร้างสรรค์
- ระบบ token 3 ชั้นแบบ Material: primitive palette → semantic role → component class บน CSS custom properties แก้ที่ศูนย์กลางที่เดียวทั้งเว็บเปลี่ยนตาม
- ทำบนสาขา develop ปล่อยเป็น v6.0.0 สาขา main ยังล็อกไว้เฉพาะงานระบบอัปเดตตามคำสั่งเดิม

## สิ่งที่ห้ามแตะ

- แคปซูลกลุ่มหลักในหน้า Discover (Master ออกแบบเอง คงเดิม)
- อนิเมชันเดิมทั้งเว็บ (พรีเมียมแล้ว ไม่ต้องปรับก็ได้)
- โลโก้และตัวอักษรแบรนด์ (Foglihten คงเดิม)

## ขั้นตอน

| ขั้น | ชื่อ | เป้าหมาย | ผลลัพธ์ที่ตรวจได้ | สถานะ |
|---|---|---|---|---|
| C1 | รากฐาน Token | สร้าง token 3 ชั้น พาเลตต์ Emerald Fresh ฟอนต์ Anuphan มาตราส่วน shape และ spacing | ไฟล์ token โหลดจริงบนหน้าทดสอบ คู่สีที่ใช้ทั้งหมดผ่านตัวตรวจ contrast AA ผ่านประตู grillme-interrogator ก่อนเขียนโค้ดจริง | ยังไม่เริ่ม รอเปิด goal |
| C2 | หน้านำร่อง Home | สร้างคอมโพเนนต์กลางและ Home ใหม่ทั้งหน้าด้วยระบบกลาง | Home ผ่านเกณฑ์กลางทั้ง 5 ข้อ ภาพเทียบก่อนหลังชัดเจน |
| C3 | ไล่ทั้งเว็บ | Search และ Discover (เว้นแคปซูลกลุ่มหลัก) Setting ตามรูปอ้างอิง ชุมชนและแพลตฟอร์มที่เหลือ | ทุกหน้าผ่านเกณฑ์กลางชุดเดียวกับ C2 ทีละกลุ่ม |
| C4 | ธีมมืด | ออกแบบธีมมืดจาก token ชุดเดียวกัน | ทุกหน้าแสดงสองธีมถูกต้อง คู่สีผ่าน AA ทั้งคู่ |
| C5 | ตรวจรวมและปล่อย | ตรวจรวบทุกหน้า ปล่อยรุ่น | develop alias = v6.0.0 โน้ตรุ่นสองภาษาครบ ทดสอบบนเว็บจริงผ่าน |

ช่วงรายละเอียดตามหลัก Rolling Wave: C1 C2 ขยายละเอียดเมื่อเริ่ม C3 C4 C5 ขยายเมื่อถึงคิว

## เกณฑ์ตรวจรับกลาง (ใช้ทุกขั้นทุกหน้า)

1. ไม่มี page error ไม่มีไฟล์โหลดไม่ได้ ไม่เลื่อนแนวนอน
2. ฟังก์ชันเดิมครบบน DOM จริง ไม่ใช่แฟล็กภายใน
3. contrast AA ทุกจุดที่วัดได้
4. ภาพเทียบก่อนหลังทุกหน้า ต้องเห็นความต่างจากเดิมชัดเจน
5. ใช้ token จากระบบกลาง 100% ตรวจด้วยการค้นหาค่า hex ในหน้า ต้องไม่พบนอกไฟล์ token
